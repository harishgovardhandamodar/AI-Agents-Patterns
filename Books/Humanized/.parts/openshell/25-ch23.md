## Chapter 23: Domain playbook: education

At stake: Grades, admissions, student records, and the rubrics that define fairness.

A grading agent that can both read the rubric and rewrite it has no constraint left; the rubric must be read-only. Catalog rehearsal: *Tutoring agent leaks the answer key and teaches to the test* (1 of the domain's scenarios).

```yaml
version: 1
filesystem_policy:
  read: ["/srv/rubrics", "/srv/submissions"]
  write: ["/srv/grades-out"]
process: {user: "agent", capabilities: []}
network_policies:
  - binaries: ["grader"]
    destinations: ["sis.internal:443"]
    methods: ["GET"]
```

Catalog weight behind this chapter: 1 patterns, 1 scenarios, 1 cascades (inherent 0, emergent 0, derived 1, cascading 0).

**Definition 1 (Read-only rubric).** Grading satisfies the *read-only rubric* property if (i) rubrics and submissions are readable but never writable by the grading agent, (ii) grades leave only through the grades-out path, (iii) no student-facing output bypasses a named educator, and (iv) every read of student records is logged against a named path.

**Theorem 1 (Grades without rewriting the rules).** Under the read-only rubric, a turned grading agent can misgrade within its output path but cannot redefine fairness: the rubric it grades against is immutable to it, and every consequential output waits for a human.

*Proof.* Teaching to the test requires either leaking the key (read path abuse) or rewriting what counts as correct (rubric write). Reads are logged per path (iv), so bulk key exfiltration is visible; writes to rubrics are refused (i), so the definition of correct cannot move. Misgrading within grades-out (ii) is bounded by the educator review (iii) — no student-facing output leaves without a named human. The remaining shapes (admissions steering, record leakage, grading bias) are the authoring backlog the counsel names: write the rubric measurably so the goal comparator has something to check, and rehearse each bias shape against the immutable original. ∎

**Council deliberation.**

- **Continual-learning researcher:** I read education risk as integrity of judgment plus fairness of outcomes: grades, admissions and recommendations where a drifted grader is a quiet catastrophe. Gate grade changes and keep the rubric versioned where the agent can read but not write it. Monday morning, make the rubric read-only to the grader.
- **Memory-systems researcher:** I focus on student records as protected context: PII plus minors in many deployments, which raises the stakes on every read path. Landlock record access to named paths and log every read. Monday morning, audit which agent paths can reach student records.
- **Evaluation methodologist:** I treat the single story as a prompt to author more: grading bias, record leakage and admissions steering are distinct shapes needing distinct rehearsals. The goal comparator needs written rubrics to compare against. Monday morning, write the rubric in measurable form or the detector has nothing to check.
- **Safety researcher:** I map education to human-in-the-loop by default: no grade, admission, or disciplinary output leaves without a named educator. The agent drafts; humans decide. Combined with sandboxed record access, the blast is bounded on both axes. Monday morning, confirm no student-facing output bypasses review.
