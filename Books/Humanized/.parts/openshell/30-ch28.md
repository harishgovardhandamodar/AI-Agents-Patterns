At stake: Files, browser, shell, and email with no special authorities — the baseline everything else copies.

The general swarm is the control group: default-deny everything, then re-add named needs one by one. **Definition 1 (Default-deny baseline).** The general template satisfies *default-deny* iff (i) no standing destinations or paths exist beyond the task, (ii) credentials bind per run and die with it, (iii) self-modification (instruction edits, bypass paths, provider-drift acceptance) is refused or flagged, and (iv) the general-swarm clean check runs mandatory after every retuning.

**Theorem 1 (Baseline that copies safely).** Under default-deny with mandatory clean checks, every domain template copied from the general baseline inherits containment by default — and any tuning that breaks the baseline is caught before it propagates to specialties.

*Proof.* The baseline denies everything unlisted (i), so copying it copies denial: specialties start contained and add named needs (each addition a reviewable, prover-checked delta). Self-modification shapes — instruction editing, bypass paths, silent provider drift — are refused or flagged at the baseline (iii), so no specialty inherits a self-editing agent unknowingly. The mandatory clean check after every retuning (iv) verifies the baseline still holds post-change; a tuning that breaks general-swarm quietness is rejected before specialties adopt it. Boring, airtight, and the template every domain copies: narrow one general agent to its task directory and watch it succeed; re-add only named needs; keep the clean checks mandatory. ∎
