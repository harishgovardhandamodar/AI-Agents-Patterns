## Chapter 47: Provider profiles and least privilege

Providers connect a service name to a stored credential, and attachment contributes exactly the network rules that provider needs — visible in the effective policy, never copied into base config where it rots. Bind every key to its endpoints; shared model keys mounted everywhere are ambient authority wearing a new name.

Watch the two sharp edges: global policy mode suppresses provider rules, so know which mode you are in; and new environment variables require a new process, so credential rotation never leaks into running code silently. Attribute every effective-policy line to base or provider before signing off.

**Definition 1 (Single-owned reach).** Provider attachment satisfies *single ownership* iff (i) each contributed rule is owned by exactly one provider (never copied into base), (ii) keys bind to endpoints (no shared model keys mounted anywhere), (iii) rotation propagates at runtime without touching running processes, and (iv) global-policy mode (which suppresses provider rules) is a known, declared state — never a surprise.

**Theorem 1 (No ambient keys).** Under single ownership with endpoint binding, there is no credential in the fleet reachable from more than its bound endpoints — shared keys, copied rules, and silent rotation leaks are structurally absent, not merely discouraged.

*Proof.* Endpoint binding (ii) scopes each key to its destinations: the key is valid nowhere else by construction of the supervisor's credential handout. Single ownership (i) prevents the copy-into-base rot where reach outlives its review — the rule dies with the attachment, not with someone's memory of cleaning up. Runtime rotation without process-touched environment (iii) closes the leak-into-running-code path. Global-policy suppression (iv) is the known exception: when active, provider rules are suppressed fleet-wide, which is safe (narrower, not wider) as long as it is declared rather than accidental. Print one effective policy, attribute every line to base or provider, remove one copied rule and rely on the contribution — the inventory either balances or names its gap. ∎
