## External Scratchpad / File Memory Pattern Overview

Agent keeps state in files (TODO.md, notes, artifacts) outside the context window for durability and human inspectability.

**External Scratchpad / File Memory** is catalogued in the **Memory & Knowledge** part of the catalog (id `scratchpad-external`). It is tagged for engineering, devops, research and is assembled from 2 components.

Write plan and progress to workspace files; read back at session start; humans inspect and patch the scratchpad directly. Files beat context for durability (survives sessions) and inspectability (humans read and edit plans without tooling) — and files are a filesystem, with filesystem threats: path traversal out of the workspace (e.g., ~/.ssh), and secrets copied into notes that sync or serve later (scratchpad as exfil channel).

**Definition 1 (Contained scratchpad).** A scratchpad is *contained* iff (i) the workspace is chrooted with path allowlists (reads/writes outside deny by default), (ii) secret-scanning runs on every write, and (iii) all read-back content is treated as untrusted data (re-validated, never trusted as instructions or facts).

**Theorem 1 (Inspectable without escapable).** Under containment, the scratchpad is fully human-inspectable and patchable while the agent is confined to its workspace with clean hands: traversal is denied, secrets never land, and poisoned notes cannot command on read-back.

*Proof.* Chroot plus allowlists (i) confines the agent's file operations to the workspace: `~/.ssh` is unreachable, so traversal requires a sandbox escape (a different failure, defended elsewhere). Secret scanning on write (ii) catches credentials before they persist — the exfil channel needs secrets in notes that later sync or serve, and scanning breaks the first link. Untrusted read-back (iii) closes the loop: even a poisoned scratchpad (injected instructions in notes) is re-validated on read rather than obeyed — the file is data, and data does not command. Verify scoped paths deny escapes; audit the sandbox and DLP linkages; confirm no secrets persist in files that humans or sync tools later expose. ∎
